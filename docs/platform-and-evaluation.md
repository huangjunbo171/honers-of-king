# 平台操作与评估

## 定位任务包并短测

1. 打开课程的「智能决策1v1」，确认小组、实验版本和可用开发资源。组队与加入实验使用课程已有的小组安排。[1v1 实验页](https://tencentarena.com/p/edu/course/7129/exp/76485)
2. 进入实验后打开「实验指南」，记录版本、终止条件、算法、可选对手、训练模式和指标。通过「下载代码」获取可用的任务包，或在已开放的实验中点击「进入开发」使用在线 IDE。
3. 在 IDE 中定位实际任务包的 `agent_ppo/`。确认适用的 TODO 和配置，保存修改。使用 IDE「运行和调试」里的预置配置运行短测，观察终端报错或「测试成功」提示。遇到异常时，从首个 traceback 定位代码和输入帧。开发结束后关闭 IDE 以归还开发资源。[平台实验指导，第 3–7 页](https://tencentarena.com/p/edu/course-content/7129/7288/209105?fileId=954901&projectId=36817)
4. 短测时记录实际观测向量的形状、动作结构、单步总奖励及各项奖励。用几帧检查换边、死亡、复活、阵亡小兵和击杀计数。

## 观测、动作和 PPO

- 环境属于部分可观测环境。智能体接收受视野约束的观测，包含英雄、兵线、建筑等实体数据。讲义以约 350 维表示观测，实际形状由任务包的特征定义和网络输入确定。
- 讲义的动作表示由六个离散选择组成。按顺序是动作键、主方向 X/Y、辅助方向 X2/Y2、目标，分类数示意为 `[12, 16, 16, 16, 16, 9]`。目标和方向分支的有效性依赖本次动作。用任务包的分支顺序、掩码和动作映射接入。
- 网络按实体分组编码，使用共享 MLP 和最大池化聚合小兵一类的可变数量实体。融合表示输入 LSTM，再由 Actor 的多个动作头与 Critic 的价值头读出。PPO 用本轮轨迹计算优势，结合策略裁剪目标、价值损失和熵项更新。本仓库在任务包的 PPO 工作流中接入了上述 LSTM、动作头和损失计算。[第 4 章讲义，第 9–21 页](https://tencentarena.com/p/edu/course-content/7129/7288/209106?fileId=954915&projectId=36818)

## 训练和评估

1. 在「训练管理」中新增训练任务。核对使用的代码和算法，填写名称及训练配置。记录资源预算、对手、训练步数或时长、可设置的随机种子和奖励权重。
2. 提交训练后，看训练日志和监控面板。短跑先确认环境交互、采样和 checkpoint 正常，再给对比实验分配相同预算。
3. 从训练任务的「模型列表」选择 checkpoint，点击「提交至模型管理」。记录训练任务 ID、模型标识、代码版本和配置。
4. 在「模型评估」新增任务。固定评估对手、英雄、局数和可用的换边设置。记录胜、负、平与异常退出。查看对局回放，核对推塔时间、对塔伤害、英雄伤害、死亡和经济变化。[平台实验指导，第 51–59 页](https://tencentarena.com/p/edu/course-content/7129/7288/209105?fileId=954901&projectId=36817)
5. 先评估简单基线，再评估进阶对手。讲义使用 `SimpleWalkBot` 和 `Advanced Baseline` 表达这两档难度。用实验指南提供的实际对手名称。模型比较以固定口径的胜率为主，奖励及回放用于解释行为变化。[第 4 章讲义，第 8、40、52 页](https://tencentarena.com/p/edu/course-content/7129/7288/209106?fileId=954915&projectId=36818)
